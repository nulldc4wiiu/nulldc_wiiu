# nullDC (Wii U)

A native Wii U port of the nullDC4Wii Dreamcast emulator.

- **[README-WiiU.md](README-WiiU.md)**: the Wii U port: installing, controls, features. With it, by release:
  [RELEASE-NOTES-WiiU.md](wiiu/RELEASE-NOTES-WiiU.md), [BENCHES-WiiU.md](wiiu/BENCHES-WiiU.md) (speed per game)
  and [KNOWN-ISSUES-WiiU.md](wiiu/KNOWN-ISSUES-WiiU.md); and [SETTINGS-WiiU.md](wiiu/SETTINGS-WiiU.md),
  [DESIGN-WiiU.md](wiiu/DESIGN-WiiU.md) and [BUILDING-WiiU.md](wiiu/BUILDING-WiiU.md).
- **[README-Wii.md](README-Wii.md)**: the original nullDC4Wii README for the Wii version, kept for reference.
  Its instructions, settings and links are for the Wii, not the Wii U.

Downloads are on the [Releases](../../releases) page. You need your own Dreamcast BIOS and games; none are included.
